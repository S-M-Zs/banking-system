The banking system I created, which is called the SMZ BANK, is a simple banking system that is made by making use of simple c++ variables. It uses arrays that store about 20 users and their information and allows users to create an account, log in and making different banking transactions.
The program off by showing the main menu which has the create account, login which has five login attempts before it blocks an account and exit. When a user logs in using the correct account number and PIN, the program then moves on to the account menu which has:
•	Check the account details
•	Depositing money
•	Withdrawing money
•	Sending money to others that are stored in the arrays
•	Then the logout which ends the program
The banking system has card and carless transactions that need PIN for card and none for cardless. The system also has receipts and confirmation of transactions which makes it much more realistic. The program uses variables, loops, if/else statements, switch statements and function for the transactions and accounts.
